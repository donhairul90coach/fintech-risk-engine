# Enterprise Credit Risk & Compliance Evaluation Engine

## 📌 Project Overview
This repository contains a lightweight, functional rule-based credit risk assessment and compliance engine built using **Vanilla JavaScript and HTML**. The application acts as a technical proof-of-concept for automated financial business rules validation, data structure telemetry logging, and risk indexing.

## 🚀 Technical Architecture & Pipeline
1. **Frontend Logic Engine (JavaScript):** Processes real-time consumer financial arrays (Monthly Income, Existing Debt, Employment Profiles) and executes high-performance threshold metrics validation under sub-16ms cycles.
2. **Deterministic Risk Parameters:** Implements operational debt-handling rules computing Debt-to-Income (DTI) metrics and flagging variable revenue anomalies (e.g., Freelance variables) to mitigate credit default exposures.
3. **Analytics Integration (Looker Studio):** Streams raw system telemetry logs directly into a centralized executive dashboard, structuring categorical data distribution fields seamlessly.

## 🛠️ System Technology Stack
- **Languages:** HTML5, CSS3, Vanilla JavaScript (ES6)
- **Data Engineering Format:** Structural Tabular Matrix (.CSV)
- **Business Intelligence Analytics:** Google Looker Studio Telemetry Dashboard
