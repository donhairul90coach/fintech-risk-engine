## 📌 Project Overview
This repository contains a production-grade, highly resilient **Multi-Tier Financial Risk Assessment & Compliance Engine** built using a modular framework. The system acts as a live corporate proof-of-concept for automated credit risk indexing, infrastructure DDoS rate-limiting, and an automated full-stack business intelligence data analytics pipeline [Accenture, MNC, Bank].

---

## 🛠️ Architecture Skillsets Showcase & Core Pipeline
A strict **Separation of Concerns (SoC)** framework was implemented to divide client presentation from core infrastructure and analytics processing [Accenture, MNC, Bank]:

### 1. 🌐 Frontend UI Layer (`index.html`)
* **Role:** Pure client-side presentation framework.
* **Skillsets:** Lightweight HTML5 structure, clean CSS3 responsive viewport scaling, and client-side data serialization. Acts strictly as a deterministic input channel, adhering to the security mandate: *"Never trust the frontend."* [Accenture, MNC, Bank]

### 2. 🛡️ Network Infrastructure Shield (`security-gateway.js`)
* **Role:** Cloud Architecture & WAF Security Simulator.
* **Skillsets:** **DDoS Resiliency & Dynamic Rate Limiting**. Implements a temporal `Timestamp Delta Check` establishing a strict **2-second velocity safety buffer**. Malicious multi-transaction flooding or automated bot sessions are immediately intercepted at the network gate (`SECURITY LOCKEDOUT`), preventing downstream server crash and optimizing cloud compute costs [Accenture, MNC, Bank].

### 3. 🧠 Core Banking Logic Server (`financial-core.js`)
* **Role:** Backend Credit Rules Enforcement & Financial Auditing Engine.
* **Skillsets:** **Risk Modeling & Business ROI Capping**. Automatically evaluates **Debt-to-Income (DTI) metrics** under sub-16ms cycles, flags Freelance income deviations, and enforces a strict **Step 2 Minimum Credit Floor of RM1,000** to eliminate negative ROI operational overhead [Accenture, MNC, Bank].

### 4. 🔀 Cloud Ingestion & Telemetry Pipeline (`Webhook API`)
* **Role:** Real-Time Asynchronous Data Streaming Layer.
* **Skillsets:** **Full-Stack Data Engineering**. Utilizes asynchronous `fetch()` API calls to stream raw transactional payloads via a live Google Apps Script Webhook endpoint straight into Google Sheets, ensuring strict tabular matrix alignment across all data cells [Accenture, MNC, Bank].

### 📊 5. Executive Business Intelligence Dashboard (`Looker Studio`)
* **Role:** Enterprise Operations Visibility Platform.
* **Skillsets:** **Data Analytics & Strategic Reporting**. Feeds directly from the cloud ingestion engine to visualize transaction approval velocities, risk rejection distribution ratios, and operational telemetry metrics via a dynamic **Scheduled Data Refresh** loop [Accenture, MNC, Bank].
